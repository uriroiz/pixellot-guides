Upload and Log Games in Pixellot

📅 Created: November 09, 2025 👤 Created by: Uri Roiz

📺 Pixellot Advantage Platform

https://advantage.pixellot.tv
Part 1: Exporting Game Video
1

Request HD Export

Locate your game in the video list and click the three-dot menu (⋮) next to the game you want to export.

2

Select "Request HD Export"

Click on Request HD export from the dropdown menu.

3

Confirm Export Request

Click Request HD export again to confirm.

⏱️ The HD processing will take approximately 20–30 minutes. You'll receive an email notification once completed.
4

Download HD File

Once processing is complete, click the three-dot menu again and select Download HD.

5

Download the MP4 File

Download the MP4 file by clicking the 3-dots icon and selecting the download option.

Part 2: Uploading to Vidswap
6

Upload New Game

Click on Add video button.

7

Select Upload Video

Click on Upload Video option.

8

Choose Content Type

Select Game as the content type, then click Next.

9

Upload Video File

Click Angle, choose 1st Angle, then browse and select the MP4 file you downloaded.

10

Confirm Upload Started

Verify the file upload has started, then click Next to proceed.

Part 3: Setting Game Details
11

Set Game Date

Select the date when the game was played using the calendar picker.

12

Set Venue Time Zone

Click on the timezone dropdown and select (GMT+02:00) Helsinki, Kyiv, Riga, Sofia, Tallinn, Vilnius.

13

Set Game Start Time

Enter the time when the game started.

14

Set Game End Time

Enter the time when the game ended.

15

Assign Home and Away Teams

Choose which team plays at Home and which plays Away.

Part 4: Creating Opponent Team
16

Create Opponent Team

Press on Create Team button.

17

Enter Team Name

Type the name of the opposing team.

Example: "מליצור נתניה" (for Hebrew teams)
18

Select Team Color

Click on Team color and choose the opposing team's jersey color.

19

Select Gender Category

Click on Gender and select either "Boys" or "Girls".

20

Save Team

Click on Create & Save to finalize the team creation.

Part 5: Finalizing Upload
21

Monitor Upload Status

⚠️ Important: The Save button will remain disabled until the file upload is complete. Please wait for the upload to finish.
22

Save Game

Click Save once the button becomes active (upload complete).

Part 6: Logging the Game
23

Open Vidswap Platform

Navigate to https://app.vidswap.com and click the Refresh button to see the newly uploaded game.

24

Wait for Video Processing

The new game will appear in the list with "No Video" status.

⏱️ Wait up to 40 minutes for the video to become available for logging.
25

Open Actions Menu

Press on the "Actions" drop-down menu for the game.

26

Start Logging

Click on Log game from the Actions menu.

27

Confirm Logging Submission

Confirm the playlist logging submission by clicking Yes.

28

Final Save

Click on Save to submit the game for logging.

29

Logging in Progress

The match will be sent for logging and show a "Being Logged" status.

📧 You will receive an email notification when the logging job finishes.
