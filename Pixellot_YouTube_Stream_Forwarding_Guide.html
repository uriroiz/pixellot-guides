Adding a YouTube stream to a Pixellot event

Do this once for each match you want to broadcast on YouTube. You need the Stream URL and Stream key from YouTube Studio.

On this page

  1. 01 Get the values from YouTube
  2. 02 Open the event in the CMS
  3. 03 Add the stream
  4. 04 Check before the match

01 Get the values from YouTube

Keep the Stream key private. Anyone who has it can broadcast to your YouTube channel. Do not send it by chat or post it in screenshots. The key and URL shown in this guide are placeholders.

In YouTube Studio, click Create, then Go live to open the Live Control Room. Select Stream and copy the two values from the stream settings.

In YouTubeField in the Pixellot CMS
Stream URL (server address)Youtube Primary Server URL
Stream keyYoutube Stream Name

Copy the Stream URL exactly as it appears in YouTube Studio. Paste the Stream key into the CMS field called Youtube Stream Name. Make sure the key belongs to the broadcast you want for this match.

02 Open the event in the CMS

Sign in to club.pixellot.tv with your federation account and open Events. Find the match and click the pencil icon in the Actions column on the far right.

Select any screenshot to enlarge it.

The Edit Event page opens.

03 Add the stream

Scroll down to Stream forwarding and click Add Stream. If the event already has a stream listed, leave it as it is.

The Add Stream Forwarding window opens.

  1. Stream Name. Enter a label of your choice, such as YouTube.
  2. Stream Target. Open the list and choose Youtube.

Two more fields appear after you choose Youtube.

  1. Youtube Primary Server URL. Paste the Stream URL from YouTube.
  2. Youtube Stream Name. Paste the Stream key from YouTube.

The screenshot uses placeholder values. Enter your own URL and key from YouTube Studio.

  1. Click Save in the Add Stream Forwarding window. This saves the stream to the event. Check that a new YouTube row appears under Stream forwarding.

The general Save button at the bottom of the Edit Event page is optional.

04 Check before the match

  • Reopen the event and confirm that the YouTube row is listed under Stream forwarding.
  • Confirm that the Stream URL and Stream key match the YouTube broadcast you intend to use for this match.
  • Add the values before the match starts. YouTube normally shows no incoming video until the match is live.
